# 📌 GEADEMP – Proyecto DAW

## 🧠 Descripción

Este proyecto ha sido desarrollado como parte del módulo de **Proyecto del ciclo DAW**.  

Consiste en una aplicación web desarrollada en **PHP puro**, desplegada en entorno local mediante **XAMPP**.

La aplicación implementa una estructura basada en el patrón **Modelo–Vista–Controlador (MVC)**, con el objetivo de organizar la lógica y mejorar la mantenibilidad del código.

---

## ⚙️ Tecnologías utilizadas

- PHP (sin frameworks)

- HTML / CSS / JavaScript

- MySQL

- phpMyAdmin

- XAMPP (Apache + MySQL)

---

## 🏗️ Arquitectura

El proyecto sigue una estructura tipo **MVC**:

- **Modelo (`modelo/`)**  

  Gestión de acceso a datos y conexión a la base de datos.

- **Vista (`vista/`)**  

  Interfaz de usuario (formularios, tablas, páginas web).

- **Controlador (`controlador/`)**  

  Lógica de negocio y gestión de peticiones del usuario.
